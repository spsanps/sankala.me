# Writing drafts and reviews

Working and historical text for the website. These files are not served directly
by the application.

- `essays/gpt7-will-have-arms/draft.md`: the working essay manuscript.
- `essays/gpt7-will-have-arms/reviews/`: comments, tracker and numbered rounds.
- `essays/gpt7-will-have-arms/assets/`: source artwork/video kept with the essay.
- `essays/gpt7-will-have-arms/archive/`: older `manuscripts/`, `references/`,
  `planning/` and `reviews/`, with original import names preserved.

Give each new essay the same structure, adding folders when material exists.
Older general website reviews live in `archive/website-content-reviews/` at
the repo root. Their statuses describe earlier review passes.

[`src/pages/essays/gpt7-will-have-arms/GPT7Essay.jsx`](../src/pages/essays/gpt7-will-have-arms/GPT7Essay.jsx); its crawler-facing
Markdown mirror is [`public/essays/gpt7-will-have-arms.md`](../public/essays/gpt7-will-have-arms.md).
Use the website's static-generation script when refreshing that mirror.
