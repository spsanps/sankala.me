# Journal cover artwork

Created September 6, 2026 with the built-in image generation tool, using existing
Paper Robots character and film artwork as references.

## Selected cover

- [WebP used by the prototype](robot-and-the-page-v2-flat-paper.webp)
- [Full-size source PNG](robot-and-the-page-v2-flat-paper.png)
- [Exact refinement prompt and selection notes](robot-and-the-page-v2-prompt.txt)

The selected image has an ordinary paper-colored RGB background. The page color
matches the observed backdrop. It is not a transparent cutout.

## First version and references

- [Original WebP](robot-and-the-page-v1.webp)

Three generation calls were made: the original composition, a rejected attempt
at a transparent background, and the selected flat-paper refinement. The rejected
output contained a painted checkerboard with no alpha channel and is not used.
WebP files are encoded copies; image content was not edited programmatically.
