# Homepage: Four frames in production (October 3, 2026)

The homepage becomes the Four frames desk San chose on October 2: one clear-line drawing with
gouache colour, full screen, that changes by hand through his four places as the words scroll.
These screenshots come from the local branch `code-drawn-art` (dev server, review hooks) and a
scratch production build with the homepage prerendered (the no-JavaScript shots).
