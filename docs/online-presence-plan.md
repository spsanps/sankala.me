### API management interest — discussed 2026-09-05

San asked whether the assistant can manage the channel through an API or another
interface. This is a feasibility discussion; no integration has been built and
no channel access has been authorized or connected.

- YouTube Data API supports channel description/banner updates, playlists,
  video uploads and metadata updates, thumbnail uploads, and caption uploads.
  YouTube Analytics API can provide authorized performance reports.
- Channel creation, name/handle selection, profile picture, and account/phone
  verification should use Google's interface. The Data API has no channel-creation
  endpoint, and channel title updates are forbidden through `channels.update`.
- A local integration requires a Google Cloud project with relevant APIs enabled,
  an OAuth client, and authorization by the channel owner. Store credentials
  outside source control; signing in and consenting happen on Google's pages.
- YouTube Studio delegated channel permissions do not grant YouTube API access.
- New unaudited API projects have uploads restricted to private viewing. Lifting
  this restriction requires YouTube's API compliance audit; do not suggest simply
  changing visibility as a workaround. Recommended first-release path: Studio
  upload, then API-assisted metadata management and analytics.
- Tools exposed in this session have no connected YouTube account or browser
  control. Plugin-directory search is also not exposed, so marketplace availability
  has not been established. This is not a claim that no YouTube plugin exists.
