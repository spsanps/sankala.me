## Setup sequence when creating the publication

1. Create a publication under San’s own account; choose the available address and
   set San Kala as the author. Review the actual creation flow, which can change.
2. Choose free publishing. Leave paid subscriptions and any payment-account
   connection unconfigured. Do not enable pledges, sponsorships, referrals with
   monetary rewards, affiliate revenue, or donations.
3. Add the proposed description, About, author photo, publication icon, and
   website/YouTube links. Check the publication’s actual welcome-page crop.
4. Prepare the first post as a draft. Check the links, read it on mobile, and
   preview the email. Keep the existing site essay online at its current URL.
5. Add a welcome email, then verify a real test subscription and unsubscribe
   path once an account exists. Do not collect addresses in local prototypes.
6. Connect the live publication from a stable `sankala.me/subscribe` route and
   the existing channel/profile links. Avoid inventing a Substack URL in live
   copy before the address is reserved.
7. Publish/send only when San is ready to send the reviewed draft. An empty
   initial list is normal; do not import personal contacts without their consent.

Substack has a built-in subscription embed if useful; a clear link is enough for
the initial site. The actual signup and welcome page are supplied by Substack,
not by the local preview’s custom CSS.
[Official embed information](https://support.substack.com/hc/en-us/articles/4407702258836-How-can-I-optimize-my-Substack-publication-for-SEO),
[welcome-page information](https://support.substack.com/hc/en-us/articles/7999279240212-What-is-a-Welcome-page-on-Substack).

## Keep the experiment small

Send a letter with each substantial release; don’t promise a weekly schedule.
Use Notes or Recommendations when there is an actual useful conversation or
publication to point to. Do not turn the setup into an additional daily content
quota. Revisit the decision after three substantial releases, using the audience
and effort measures in the [strategy note](2026-09-audience-and-publishing.md).
