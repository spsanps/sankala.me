# Server support files

`essay-previews/generated/` contains the crawler-facing article HTML exported
as JavaScript modules. The public Vercel entry point remains `api/og.js`; it
imports these modules for social previews and crawler requests.

- `gpt7-will-have-arms.js`: generated by
  `scripts/essays/generate-static.mjs` / `npm run generate:essay-static`.
- `eai-challenge.js`: the existing static representation of the EAI write-up.
  No dedicated EAI generator is currently present in the repo.

These support files live outside `api/` so their role is clear and they are not
mistaken for standalone request handlers. Public essay and Markdown URLs are
unchanged.
