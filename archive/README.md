# Archive

This directory contains historical or source files that are intentionally kept out of the deployed website.

- [`resumes/`](resumes/README.md) contains superseded resume versions.
- [`source-assets/`](source-assets/README.md) contains original photos and certificate copies that were previously stored in the unused root `assets/` directory.
- `website-content-reviews/` contains older website text, link audits and content-cleanup reviews.

Files used by the live site belong under `public/`. Application code should not link directly into this archive.
